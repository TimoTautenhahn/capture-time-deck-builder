# Vision-to-Slide Composer

Pipeline that turns image collections into structured slide narratives with a lightweight web control surface.

## Architecture

Image intake -> vision/caption stage -> slide assembly -> export.

## Stack

Python web app, automation scripts

## Why this matters

Built as an Applied AI Architecture showcase: clear system boundaries, agent/tooling seams, and a path from prototype to operable demo.

## Safety

This repository is a **sanitized portfolio export**. Secrets, customer identifiers, and private credentials have been removed. Configure your own environment variables locally via `.env.example` if present.
